# Material R15 · GPU 光学渲染

## 查看与调节

通过本地 HTTP 服务或 HTTPS 部署访问本目录的 `index.html`，不要直接双击 HTML。
页面继续使用原有八类 STL 和矿物目录，不需要在线加载模型或渲染库。

- **视角 → 渲染质量**：自适应（默认）／流畅／精细。
- **图层 → 折射焦散**：独立控制穿过晶体后落在下方承接面的聚光。
- **图层 → 光学色散**：控制 RGB 折射差异，不再用 CSS 去饱和伪装开关。
- **图层 → 光谱示意线**：原有光谱教学图，和真实光路求交得到的焦散分开。
- **暂停**：停止场景时间；静止且无交互时不重复提交重型渲染。
- **固定到对照**：记录当时的晶型、颜色和所有光学滑杆值，不再回读矿物默认参数。

## 渲染流程

1. CPU 解析原始 `models/8-crystals.stl`，仍按原映射分为八组，保留全部 86,056 个三角面用于外形绘制。
2. meshoptimizer 为光线查询生成光学 LOD：目标每组 384 个三角面，简化器相对误差参数为 0.01，误差限制优先于目标面数。这不是对原 STL 的覆盖保存，也不是独立测量的误差保证。
3. 在光学 LOD 上建立无栈 BVH，上传 GPU。旋转时仅变换光线，不重建加速结构。
4. 视线先在表面折射，再查询内部出口，依据实际光路长度计算 Beer–Lambert 吸收、Fresnel 反射和全内反射。取消原来的按透光率降低表面 alpha 的重复混合。
5. 独立计算着色器投射 RGB 光线，穿过同一个光学 LOD 后投到水平承接面；以固定能量的软光斑累加近似焦散。不是噪声贴图，也不是水波模拟。
6. HDR 中合成环境、焦散和晶体，配合 4× MSAA、轻量泛光及 ACES 色调映射。

| 质量 | 视线处理 | 内部反射上限 | 焦散光线 |
| --- | --- | --- | --- |
| 自适应 | 共享绿色几何路径，出口处分离 RGB | 4 | 64 × 64 × 3 |
| 流畅 | 同上，较低初始分辨率 | 2 | 64 × 64 × 3 |
| 精细 | RGB 三条独立折射路径 | 6 | 96 × 96 × 3 |

自适应模式在持续低帧率时降低离屏渲染分辨率，不修改外形网格。网页后台暂停工作；恢复焦点和缩放不再无限新建 GPU 设备。重新选择质量档位会释放旧资源后重建。

## 近似与边界

- 这是实时视觉模拟，不是光谱路径追踪器、矿物学实测数据或 WebGPU 硬件光追 API。
- 查询网格采用上述 LOD；RGB 代替连续光谱，内部反射次数有限。自适应／流畅档共享几何路径是额外的性能近似。
- 焦散是有限数量光子的软光斑估计；对照中的两个样本分别计算，不模拟样本间互相折射或遮挡。
- 反射和透射使用程序化摄影棚环境，不读取页面 DOM 后方的文字。
- WebGPU 初始化失败、设备丢失或不受支持时，换用**独立的 2D Canvas 基础预览**。它不提供同等级的折射／焦散；页面明确提示，并在视角面板提供重试。

## 构建与检查

构建输出仍为 `js/material-vgpu.js`，可随现有静态目录直接部署。
Node 22.18+ 可运行本项目使用原生 TypeScript stripping 的测试命令。

```sh
npm ci
npm run check
npm run build
```

`check` 包括 TypeScript 检查、五个着色器入口及其依赖的验证、八类源网格与光学 BVH 的自动化测试。着色器检查脚本也解析验证结果，避免工具输出诊断却返回零退出码的漏检。

## 参考及许可

## R16 显示与兼容预览修正 · 2026-09-29

- 修正 CPU 回退预览逐 N 面抽样造成的缺面：复用完整的简化网格，重新计算面法线，逐面投影与实体明暗填充。若简化失败，保留全部源网格作为回退，而不跳面。
- CPU 预览只提供几何形态／明暗，不声称模拟 GPU 的折射／焦散。视角面板显示三语兼容提示与重试按钮；支持 `?renderer=basic` 显式检查回退路径，点击“重试 WebGPU”退出该测试模式。
- GPU 的 WGSL、原 STL、光学参数与源网格均保持不变。复用同一 LOD 同时生成 CPU 预览和光学 BVH。
- 新图层开关：左侧介绍、当前晶体名称、晶体选择列表，独立显示/隐藏，不改变当前矿物／晶系。隐藏内容退出键盘焦点；图层面板始终可用于恢复。
- 收紧窄屏标题排版，晶体列表改为可滚动，防止标题断成孤字、选项被底部控制台裁切；顶部模式栏和底部控件保持在视口内。
- 回退绘制限速约 30fps；暂停且状态不变时跳过重复绘制。
