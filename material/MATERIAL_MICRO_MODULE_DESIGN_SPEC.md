# NEW CELESTIAL ARCHIVE · 03 物质 / 微观板块设计规范

> 状态：MATERIAL R14 已实现并通过浏览器验收  
> 日期：2026-08-30  
> 适用目录：`material/`  
> 参考标准：已通过的天体 06.2 视觉系统、地球 EARTH R10 交互系统

## 1. 板块定位

微观板块不是独立的新网站，而是“天体 → 地球 → 物质”连续叙事的第三层。

- **天体 / COSMIC**：回答天体在宇宙中的位置、轨道、族群、光谱和时间关系。
- **地球 / EARTH**：回答陨石何时、在哪里、以何种记录方式抵达或被发现。
- **物质 / MATERIAL**：进入被选中的陨石样本，回答它由什么组成、不同波长下如何响应、内部结构和晶体系统如何组织。

网页目标：原图负责看见整体分类；网页继续打开静态图中难以同时表达的成分层级、光谱变化、内部结构、晶体空间关系和样本之间的比较。

## 2. 三个板块必须共同保持的内容

### 2.1 品牌与整体视觉

- 左上角统一使用“新-天象图库 / NEW CELESTIAL ARCHIVE”Logo、名称和板块编号。
- 继续使用黑色 / 深棕空间、白色细线、圆环、刻度、十字轴、彩色数据和几何符号。
- 主背景保持暗色，不把原始海报作为页面背景。
- 原图只进入“解读”抽屉，用于看见整体、理解网页如何拆解原图。
- 默认不使用全屏 Bloom；只有当前选中样本、晶体或谱线允许局部发光。

### 2.2 左侧三维度切换

三个页面均使用天体 06.2 左侧的纵向“观察尺度”导航，不再增加顶部重复入口。

| 编号 | 中文 | 英文 | 状态 |
|---|---|---|---|
| 01 | 宇宙 | COSMIC | 跳转天体页 |
| 02 | 地球 | EARTH | 跳转地球页 |
| 03 | 物质 | MATERIAL | 微观页高亮 |

要求：

- 样式、宽度、线段、编号和激活色与天体 / 地球一致。
- 三个链接携带同一个发布版本参数，避免浏览器显示旧页面。
- 从地球进入物质页时保留所选陨石身份；没有选中对象时进入默认代表样本。

### 2.3 顶部公共按钮

公共按钮从左到右统一为：

`解读 EXPLAIN → 筛选 FILTER → 语言 LANGUAGE → 尺寸 UI SIZE → 资料 DATA`

从页面右侧向左阅读时固定为：

`资料 DATA ← 尺寸 UI SIZE ← 语言 LANGUAGE ← 筛选 FILTER ← 解读 EXPLAIN`

各页面专属按钮放在“解读”左侧，不打乱五个公共按钮的相对顺序。微观页建议采用完整排列：

`视角 CAMERA → 图层 LAYERS → 解读 → 筛选 → 语言 → 尺寸 → 资料`

| 按钮 | 三个板块共同规则 | 微观板块内容 |
|---|---|---|
| 视角 | 专属按钮，位于公共按钮左侧 | 整体、剖面、晶格、光谱空间、对照视角 |
| 图层 | 专属按钮，位于公共按钮左侧 | 外壳、矿物相、元素、晶格、标注、谱线 |
| 解读 | 同位置、同尺寸、同抽屉逻辑 | 原图、视觉编码、成分/光谱/晶体关系说明 |
| 筛选 | 同位置、同选择反馈 | 样本类别、成分、晶系、数据完整度 |
| 语言 | 中文 / 日本語 / English | 正式矿物名、分类名、化学式和单位不强制翻译 |
| 尺寸 | 精细 100%、标准 115%、舒适 130%、大号 145% | 只缩放 UI，不改变中央三维样本比例 |
| 资料 | 数据来源与字段说明 | 样本、成分、光谱、晶体数据及原图来源 |

### 2.4 抽屉与基础交互

- 抽屉从右侧进入，顶部标题固定，内容本身正常滚动。
- 同一时间只打开一个工具抽屉；再次点击按钮或按 `ESC` 关闭。
- 关闭按钮、边框、标题字号、双语小标题与天体 / 地球统一。
- 被选中的样本使用独立的“样本档案 / SAMPLE INSPECTOR”，不与工具抽屉混为一类。
- 拖动用于旋转或观察局部；滚轮用于微观层级推进，不同时承担无关功能。
- 复位按钮恢复视角、层级和筛选，但保留语言与界面尺寸偏好。

## 3. 微观板块五个主阅读模式

顶部中央沿用五段式导航，建议内容如下：

| 编号 | 模式 | 英文 | 主要表达 |
|---|---|---|---|
| 01 | 样本 | SAMPLE | 陨石整体外形、来源档案、质量、类别与可用数据概况 |
| 02 | 成分 | COMPOSITION | 从陨石整体拆到矿物相、元素与独有物质，支持分层和爆炸视图 |
| 03 | 光谱 | SPECTRUM | 以波长控制透光率 / 反射率 / 吸收响应；不同物理量必须分开标注 |
| 04 | 晶体 | CRYSTAL | 晶系、晶胞、轴向与空间关系，可旋转并进入局部晶格 |
| 05 | 对照 | COMPARE | 两个或多个样本在成分、谱线、晶系和数据完整度上的并列比较 |

模式切换原则：同一选中样本在五个模式中保持身份，不重新随机生成对象。

## 4. 页面主构图

### 4.1 左侧叙事区

- 显示 `03 / 物质尺度`、当前模式标题和一句解释。
- 当前样本名称、陨石分类与来自地球页的事件信息在此形成上下文。
- 不堆叠大段说明；详细知识进入“解读”或“资料”。

### 4.2 中央可视化区

- 默认显示可旋转的陨石样本，而不是原图照片。
- 从外向内的层级建议为：外观 → 剖面 → 矿物相 → 晶体 / 晶格。
- 色彩是数据编码：一个颜色在同一模式中只表达一个变量。
- 远景使用低成本轮廓 / 点云，中景使用几何符号，近景才加载晶体细节。

### 4.3 右侧信息区

- 未选择局部对象时显示样本总览。
- 选择矿物、元素、谱线或晶体后切换为对应档案。
- 明确显示字段来源、单位、缺失值和推算值，不能把视觉模拟当成测量数据。

### 4.4 底部控制区

沿用天体 / 地球的底部横向控制语言，但内容改为微观变量：

- 主滑杆：当前数据集真实覆盖的波长或观察层级。
- 快捷区间：可见光、近红外、全谱；没有真实数据时禁用而不是伪造。
- 播放：自动扫描波长或逐层拆解。
- 对照：加入 / 退出对照样本。
- 复位：回到样本整体与默认波长。

## 5. “解读”板块规范

现有素材：

- `assets/meteorite-chart-02.jpg`：陨石成分相关原图。
- `assets/meteorite-chart-04.jpg`：陨石对照表与颜色 / 分类系统原图。

使用规则：

- 原图保持自身比例，以适中的预览尺寸居中显示，不铺满抽屉。
- 原图不能吸顶，也不能在向下滚动时遮挡说明文字。
- 点击原图对应区域，可切换到“样本 / 成分 / 光谱 / 晶体 / 对照”模式。
- 点击图片本身可以放大查看，热点按钮优先执行模式跳转。
- 解读内容至少包含：整体表达、颜色与形状编码、成分层级、光谱指标差异、七种晶系、数据缺失与推算说明、网页比原图新增的能力。

解读中的四项设计原则保持与天体页相同的排版：

1. **网页目标**：打开成分、波长、内部结构和晶体空间关系。
2. **保留**：暗色空间、白色细线、刻度、圆环、彩色分类与几何符号。
3. **空间化**：平面分类 → 可旋转样本；色块 → 有厚度的矿物相；晶系示意 → 可进入的晶格空间。
4. **性能原则**：默认无全屏 Bloom；由整体到局部按需增加细节，只有选中对象启用局部发光。

## 6. 数据语义与真实性边界

- **成分**、**矿物**、**元素**是不同层级，界面不可混写。
- **透光率**、**反射率**、**吸收率**是不同指标，图例、单位和曲线必须明确区分。
- 晶系、晶胞参数、空间群只在数据有依据时展示；缺失字段显示 `— / NO DATA`。
- 推测颜色、模拟剖面、程序生成晶体必须标记为视觉模拟，不伪装成显微照片或实验结果。
- 从地球页带入的是“事件 / 陨石记录身份”；进入微观页后再关联可用样本数据，不能默认每条地球记录都有完整材料分析。
- “资料”抽屉必须列出数据库、原始文件、字段解释、单位、更新时间和本地快照版本。

## 7. 语言、尺寸与状态共享

- 使用现有共享偏好：`nca-lang`、`nca-ui-size`。
- 三个板块切换后语言与界面尺寸保持不变。
- 中文、日本語、English 必须覆盖导航、按钮、抽屉、提示词和空状态。
- 化学式、正式分类、样本编号和 SI 单位保留原始形式，解释文字再翻译。
- 当前选中样本、模式、波长和图层应形成清晰的页面状态；刷新后至少恢复语言、尺寸和当前样本。

- 微观页不再是静态占位页。
- 三维度导航、品牌、暗色调与天体 / 地球一致。
- 公共按钮名称、尺寸和相对顺序完全一致。
- 五个主模式可切换，选中样本身份不丢失。
- 原图只出现在解读中，比例正确、尺寸适中、滚动不遮挡文字。
- 中文、日本語、English 和四档 UI 尺寸均可用。

## 12. MATERIAL R13 实施与验收记录

- 渲染核心采用 [Vercel Labs / vgpu](https://github.com/vercel-labs/vgpu) `0.3.1`；星空、HDR 太阳和同源照明逻辑参考其 MIT 许可的 Earth 示例。
- 唯一三维模型源为 `8晶体.stl`，不再使用 OBJ、MTL、C4D、GLB 或程序生成替身。运行时解析 8/8 空间网格，共 86,056 个三角面。
- 八类源网格从左到右固定映射到等轴、六方、四方、三方、单斜、斜方、三斜与“正方源模型”；最后一项保留源文件语义，不将其冒充标准晶系。
- 中央模型使用真实 STL 顶点与法线；材质实时计算透光、折射、色散、菲涅耳边缘和太阳高光。太阳在星空中缓慢旋转，并与晶体共享一个光源方向。
- 外环 50 个矿物图标保留原海报的名称、色相和几何语言；点击矿物或八类网格都会更新中央晶体及样本档案。
- `01 样本`显示真实网格来源与面数；`02 成分`显示同晶系关系；`03 光谱`响应波长与色散；`04 晶体`直接切换八个 STL 网格；`05 对照`并置当前与固定样本。
- 透光率、折射率与色散继续标记为 `VISUAL SIM.`，不能解释为实验或矿物学测量值。
- WebGPU 可用时运行 vgpu；不可用时仍使用同一 STL 网格的 Canvas 2D 投影降级，不再回退到程序轮廓。
- 浏览器实测：WebGPU 状态为 `VGPU · STL 8/8 · 86,056 TRI`，五个栏目、八类切换、对照和中英切换均通过，控制台零错误。
- 外圈依据视口宽高共同缩放，完整进入顶栏与底栏之间的可点击安全区；每个节点具有 42 px 命中区域，并提供完整双语名称和键盘焦点状态。
- 中央光学校准场包含可折射的细网格、同心圆、十字轴与波长色带；用户可通过晶体后的线条偏移、边缘色散和旋转太阳高光直接辨认透光率与折射率变化。
- 代表矿物常驻标签按圆环方位自动朝内排版，其他标签在悬停、聚焦或选择时显示，避免顶部菜单和底部控制栏遮挡。
- 星空由多层不同粒径的冷白粒子组成，粒子仅做轻微异步闪烁；同一程序化背景参与晶体折射、反射和色散采样，使透光率变化可被直接观察。
- 外环尺寸与中心由实际顶栏、内容区和底栏边界动态计算，顶部、底部节点均保留命中余量；窗口缩放与 UI 尺寸变化会重新排版。
- 拖拽期间禁止浏览器文本选择并捕获指针，松开、取消或丢失捕获时统一结束交互，避免误选文字后卡住。
- 页面从后台返回、在窗口间移动标签页或设备像素比改变时会触发表面重配；检测到停帧时重启 WebGPU 渲染，Canvas 降级层也使用同一套恢复逻辑。
- 八个源网格均可独立选择；第八项作为源文件中的“正方源模型 / SOURCE SQUARE”呈现，不伪装成第八种标准晶系，也不再回落显示 STL 01。

## 13. MATERIAL R14 代表波长与棱镜光路

- 外环对象是矿物而非化学元素。USGS 光谱库以“随波长变化的反射光谱”记录矿物特征，因此不把任一颜色冒充矿物唯一实测波长。
- 网页将原海报 RGB 色相匹配到 380–720 nm 的代表波长，并以颜色饱和度生成色纯度；灰、白、黑等无彩色采用低色纯度白光。该映射仅服务视觉交互。
- 选择矿物后，代表波长、色纯度、中央晶体色、入射白光、折射彩光与粒子颜色同步更新；用户手动拖动波长滑块时进入高色纯度观察状态。
- 中央光路参考 [vgpu Prism Hero PR #356](https://github.com/vercel-labs/vgpu/pull/356) 的白光、色散、HDR 与 dust 逻辑，使用页面既有 vgpu/WebGPU 渲染管线重新实现，不复制其成品画面。
- 光路收束在中央观察环：右上白光进入晶体，左下以当前代表波长为中心形成色散光扇。白光段粒子保持白色，穿过晶体后的粒子随波长与色纯度着色。
- 晶体表面增加与真实 STL 顶点空间绑定的微小闪光粒子；粒子随晶体旋转，直接受透光率、背光、菲涅耳与色散控制。
- 数据抽屉加入 [USGS Spectral Library](https://www.usgs.gov/labs/spectroscopy-lab/usgs-spectral-library) 和 vgpu Prism Hero 源码记录，解读区明确区分真实光谱与网页代表波长。
