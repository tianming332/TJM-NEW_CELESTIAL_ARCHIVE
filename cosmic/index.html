数据与参考 DATA / REFERENCES

网页运行时读取本地数据；NASA/JPL 用于离线抓取、校验和补充。

NASA / JPL Small-Body Database单个小天体身份、轨道与物理参数。 NASA / JPL SBDB Query API批量筛选与本地数据下载。 NASA / JPL Horizons指定时间下的位置、星历与轨迹。 NASA / JPL CNEOS — NEO Groups近地天体轨道分类说明。

摄影背景 / PHOTOGRAPHIC BACKGROUNDS

可选深黑、Webb “Cosmic Cliffs”、Webb First Deep Field、Webb “Pillars of Creation” 与 Hubble eXtreme Deep Field。NASA / ESA / CSA / STScI 等署名随具体影像保留。所有背景仅用于摄影展示，不与本页太阳系小天体坐标配准。
